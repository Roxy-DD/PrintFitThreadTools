# Fusion 360 3D 打印标准件适配插件 (PrintFitThreadTools)

![版本](https://img.shields.io/badge/version-1.1.1-blue)
![平台](https://img.shields.io/badge/platform-Fusion%20360-orange)

专为 3D 打印设计的 Fusion 360 自动化辅助插件。用于将 McMaster-Carr 或其他渠道导入的标准件（如螺丝、螺母、轴承、齿轮等），生成带有 3D 打印公差的容纳底座、布尔切割刀具或补偿副本。

![Plugin Overview Placeholder](docs/images/overview.png)

## 功能特性

### 1. 公差适配策略
支持针对不同几何类型的计算策略：
- **径向缩放 (仅 XY 方向)**：保持 Z 轴（高度）尺寸不变，仅对 XY 轴（径向）进行缩放，适用于螺纹孔等需要保持轴向尺寸的几何体。
- **等比缩放 (XYZ 方向)**：在 XYZ 三个方向进行均匀放大。
- **面偏移 (法向等距)**：通过拓扑计算向外进行法向面偏移，适用于非对称或不规则形状的零件。

### 2. 圆心提取
支持从不完整几何体中提取特征圆心。
- **自动提取**：在选中部分圆柱面时，可自动提取其圆柱中心作为基准点。
- **手动指定**：支持通过手动点选圆弧或顶点指定中心基准。

![Smart Center Placeholder](docs/images/smart_center.png)

### 3. 封头与单向延伸
针对内六角或带有倒角的螺丝头部，支持生成包裹头部的实体。
- **特征获取**：点选参照面后，算法自动获取螺丝头部的最大外接圆直径。
- **实体生成**：生成包含倒角在内的实心圆柱体，并沿指定方向延伸，最后与生成的工具实体进行布尔合并。

### 4. 参数作用域隔离
- 对同一零件进行多次不同的容差操作时，插件会自动生成带数字后缀的独立用户参数（如 `PF_M4_1_Clear`），避免不同操作间的参数冲突。

### 5. 预览性能优化
- 针对高面数模型，在拖拽滑块预览时，系统将跳过耗时的布尔切除计算。
- 预览阶段取消布尔运算时，生成的底座会显示为 30% 半透明状态，以便观察内部刀具形状；点击确认后执行最终的布尔切除。

## 📥 安装说明

1. 下载或克隆本仓库到本地。
2. 打开 Fusion 360。
3. 点击顶部菜单栏的 `实用程序 (Utilities)` -> `附加模块 (Add-ins)`。
4. 切换到 `插件 (Add-ins)` 选项卡，点击绿色加号 `+`，选择本仓库的 `PrintFitThreadTools` 文件夹。
5. 在列表中找到 `PrintFitThreadTools`，勾选 `启动时运行 (Run on Startup)` 并点击 `运行 (Run)`。

## 🚀 使用指南

1. **选择零件**：在视图中选择导入的标准件。
2. **选择适配策略**：根据模型类型选择径向、等比或面偏移。
3. **设置公差**：选择预设的 3D 打印公差或手动输入。
4. **生成底座**：选择所需的外部底座形状（方块、六角、圆柱形等），并调整边距参数。
5. **确认生成**：点击确定，结果将作为参数化特征生成在时间轴中。

## ⚙️ 专家模式

在“专家模式”选项卡中，可以进行以下操作：
- 为 X/Y/Z 三轴分别指定公差补偿值。
- 关闭底座生成和布尔运算，仅输出放大后的实体刀具。
- 手动覆盖全局缩放比例或高度参数。
