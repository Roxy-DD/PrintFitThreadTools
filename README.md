# Fusion 360 3D 打印标准件适配插件 (PrintFitThreadTools)

![版本](https://img.shields.io/badge/version-1.1.1-blue)
![平台](https://img.shields.io/badge/platform-Fusion%20360-orange)

专为 3D 打印设计的 Fusion 360 自动化辅助插件。用于将 McMaster-Carr 或其他渠道导入的“零公差标准件”（如螺丝、螺母、轴承、齿轮等），一键生成带有精准 3D 打印公差的**容纳底座**、**布尔切割刀具**或**补偿副本**。

## 🌟 核心特性

### 1. 智能公差引擎 (Smart Fit Engine)
支持针对不同几何类型的专属计算策略：
- **径向缩放 (仅 XY 方向)**：智能锁定 Z 轴（高度），仅对 XY 轴（径向）进行缩放。完美保护了螺距和牙型角，专为螺纹孔设计。
- **等比缩放 (XYZ 方向)**：全向均匀放大，计算极快，适合大部分对称、规则的实体零件。
- **真实面偏移 (法向等距)**：针对极度不规则、残缺、非对称的异形件，通过拓扑计算自动向外进行严格的法向面偏移，保证每一个死角的公差绝对均匀！

### 2. 全自动智能定心 (Auto-Center Heuristic)
抛弃传统的“包围盒中心”！插件底层内置了特征嗅探引擎。
- **全自动提取**：面对剖切了一半的残缺螺丝，算法能自动遍历所有残余表面，嗅探出圆柱特征并提取其最初的绝对数学原点！**用户闭眼点击即可完美居中！**
- **手动接管**：如果极度异形，您仍可手动点选任意残破的“半圆弧”或“顶点”强制覆盖原点。

![Smart Center Placeholder](docs/images/smart_center.png)
*(需要一张截图：鼠标放置在一半残缺的螺丝边缘，展示智能圆心提取功能)*

### 3. 智能无缝封头与向外突破 (Smart Seal & Breakthrough)
针对内六角、沉头或带有复杂倒角的螺丝，传统算法在布尔切割时往往留下残留。
- **选面突破**：只需点击坑底，算法将自动获取螺丝全头部的“最大外围宽度”。
- **无死角包容**：自动生成涵盖整个螺丝头及斜面倒角的完美实体，并向外延伸。生成的完美刀具无论是正切还是反切，都能精准挖出不留残渣的沉头孔。

### 4. 多重参数隔离机制 (Namespace Scoping)
- 对同一个零件复制 100 次并进行 100 次不同的容差操作，参数互不污染！插件会自动侦测并生成带数字后缀的独立全局变量（如 `PF_M4_1_Clear`），彻底杜绝连锁联动的灾难。

### 5. 极致性能：自适应降级渲染 (Adaptive UI Degradation)
- **极限抗压**：针对工业级多面数模型，在用户拖拽滑块的高频“预览阶段”，系统将自动熔断极其耗时的 C++ 布尔切除计算。
- **透明度幽灵渲染**：切除被熔断时，生成的底座会自动变成 30% 半透明的“幽灵玻璃态”，让用户以 60FPS 的丝滑帧率隔着底座肉眼洞察内部刀具的形变！点击【确定】后才释放算力进行完美切除。

## 📥 安装说明

1. 下载或克隆本仓库到您的电脑。
2. 打开 Fusion 360。
3. 点击顶部菜单栏的 `实用程序 (Utilities)` -> `附加模块 (Add-ins)`。
4. 切换到 `插件 (Add-ins)` 选项卡，点击绿色加号 `+`，选择本仓库的 `PrintFitThreadTools` 文件夹。
5. 在列表中找到 `PrintFitThreadTools`，勾选 `启动时运行 (Run on Startup)` 并点击 `运行 (Run)`。

## 🚀 使用指南

1. **选择零件**：在屏幕上点选您导入的螺丝、轴承或残缺异形件。
2. **选择适配策略**：根据您的模型类型选择径向、等比或真实面偏移。
3. **选择公差**：内置常见 3D 打印公差（如 +0.20mm 宽松，+0.10mm 滑动配合）。
4. **生成底座**：选择想要的外部底座形状（方块、六角、圆柱形等），并调整横向、纵向边距。
5. **确定**：一切都将在时间轴中完全参数化地生成，绝不卡顿。

## ⚙️ 进阶专家模式

在“专家模式”选项卡中，您可以：
- 为 X/Y/Z 三轴分别指定完全不同的公差补偿值。
- 关闭布尔运算，仅输出放大后的实体刀具（用于更复杂的组件装配）。
- 手动覆盖全局缩放比例或指定高度。
